You are given multiple views of the SAME 3D object.

The object has ONE dominant plane of reflective symmetry.

For each image, identify the most visible pair of corresponding symmetric structural features (legs, arms, wheels, handles, holes) that are mirror images of each other across the global symmetry plane.

For each image:
1. Identify the most prominent symmetric structural pair visible in that view.
2. Return:
   - obj_id 1: the LEFT instance of the symmetric structural feature,
   - obj_id 2: the RIGHT instance of the same feature (mirror image across the plane).

The midpoint between each pair lies on the symmetry plane trace in that view.

IMPORTANT RULES:
- Identify the SAME type of structural feature consistently across all views.
- Use the SAME global symmetry plane consistently across all views.
- Both points MUST lie on the visible object surface in each view.
- The midpoint between each pair must lie on the projected plane trace.
- If the primary feature is not visible in a view, use the nearest visible symmetric pair.
- Infer the global plane from ALL views jointly before answering.
- Do NOT collapse both points to the same location.

Output format (one entry per image, separated by semicolons):

<points coords="1 1 Xleft Yleft 2 Xright Yright; 2 1 Xleft Yleft 2 Xright Yright; 3 1 Xleft Yleft 2 Xright Yright">

Where each entry is: image_index obj_id X Y
- obj_id 1 = LEFT structural feature
- obj_id 2 = RIGHT structural feature (mirror)

Return ONLY the <points ...> block.
