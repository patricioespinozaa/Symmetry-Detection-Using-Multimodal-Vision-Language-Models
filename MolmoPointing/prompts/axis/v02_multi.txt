You are given multiple views of the SAME 3D object.

The object has ONE dominant axis of rotational symmetry.

For each image, identify the widest visible cross-section and return the leftmost and rightmost silhouette boundary points at that height.

For each image:
1. Find the height where the object appears widest.
2. Return:
   - obj_id 1: the leftmost silhouette boundary point at the widest cross-section,
   - obj_id 2: the rightmost silhouette boundary point at the same height.

The midpoint between each pair lies on the projected axis in that view.

IMPORTANT RULES:
- Within each image, the two points MUST be at approximately the same height (same Y coordinate).
- Both points MUST lie on the visible silhouette boundary.
- Use the SAME global axis consistently across all views.
- Choose the widest visible cross-section independently for each view.
- The midpoint between each pair must lie on the projected symmetry axis.
- Infer the global axis from ALL views jointly before answering.
- Do NOT collapse both points to the same location.

Output format (one entry per image, separated by semicolons):

<points coords="1 1 Xleft Yleft 2 Xright Yright; 2 1 Xleft Yleft 2 Xright Yright; 3 1 Xleft Yleft 2 Xright Yright">

Where each entry is: image_index obj_id X Y
- obj_id 1 = LEFTMOST silhouette point at the widest cross-section
- obj_id 2 = RIGHTMOST silhouette point at the same height

Return ONLY the <points ...> block.
